# Аудит статических ассетов

Дата: 2026-11-25.

Проверены все 89 файлов исходного `public`, актуальные исходники `src`, CSS,
CMS-интеграция и скрипты проекта. Codebase Memory недоступен (Transport closed),
поэтому ссылки сверены непосредственно с файлами: строковые URL разобраны через
TypeScript AST, отдельно проверены CSS URL и динамические пути декора и социальных
иконок. Содержимое прошлых сборок не использовалось как доказательство использования.

## Результат

После очистки в `public` осталось **88 используемых файлов, 16 284 276 байт**.

- Все локальные ссылки разрешаются в существующие файлы.
- Неиспользуемых файлов в `public` не осталось.
- Побайтных дубликатов среди исходных 89 файлов нет.
- Все растровые изображения и SVG успешно прочитаны Sharp.
- SVG-компоненты иконок используются компонентами сайта и оставлены.

Проверка охватывает обычную и новогоднюю темы, аудитории «Для всех», «Для детей»,
«Для взрослых», мобильные и десктопные изображения. Ресурсы метаданных, шрифт,
видео, постер и скрипт showcase также используются.
